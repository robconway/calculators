# NDDH Anaesthetic Calculators

Local clinical reference tools for North Devon District Hospital.

## Tools

- **la-calculator.html** — Local Anaesthetic Maximum Dose Calculator (for nerve / fascial plane blocks)
- **awake-intubation-topicalisation.html** — Topicalisation calculator for awake tracheal intubation

## Notes

These are clinical aids only. Always verify against current local guidelines and
individual patient circumstances. Intended for local use at North Devon District Hospital.

Both pages are self-contained single HTML files with no dependencies and carry a
`noindex` tag so they are not listed by search engines.
